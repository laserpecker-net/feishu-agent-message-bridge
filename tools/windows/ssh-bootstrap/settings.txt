#  result_dir = where configure.ps1 writes result-<HOSTNAME>.txt

#      result file goes next to this package (the folder you unzipped to)

#  for example a share on YOUR OWN network that those machines can reach.

#  not there. When in doubt, leave it commented out.
#
#  Examples:
#      result_dir = \\their-nas\deploy\results
#      result_dir = D:\ssh-results
